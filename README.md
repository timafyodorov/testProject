# Проект "Фильтрация и сортировка данных о банковских операциях"

## Описание: Проект "Фильтрация и сортировка данных о банковских операциях" представляет собой решение для обработки и анализа данных банковских транзакций.

## Тестирование: В рамках этого проекта реализованы две ключевые функции:
1) filter_by_state:
- Эта функция принимает список словарей, которые представляют банковские операции, и параметр 'state'.
Также она возвращает новый список, включающий только те операции, у которых значение ключа 'state' совпадает с переданным в функцию значением. 
- По умолчанию параметр 'state' имеет значение 'EXECUTED'
2) sort_by_state:
- Эта функция принимает список словарей с данными банковских операций и параметр, определяющий порядок сортировки. 
- Она возвращает новый список, где операции отсортированы по дате. 
- Параметр порядка сортировки по умолчанию установлен на 'True', что означает сортировку по возрастанию.
3) Возможность тестирования masks
Возможность тестирования widget
Возможность тестирования proccesing
