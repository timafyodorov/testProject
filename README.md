В данном проекте есть такие функции, как filter_by_state она выполняет фильтрацию списка словаря и возвращает отсортированный список.
Также есть функция sort_by_date, она принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание). Функция должна возвращать новый список, отсортированный по дате (
date
). 
Функция get_mask_card_number - маскирует номер банковской карты по определенному правилу.
Функция get_mask_account - маскирует номер банковского счета по определенному правилу.
